# Firmware (ESP32)

Código del ESP32 DevKit v1 con PlatformIO (framework Arduino).

- Credenciales en `include/secrets.h` (copiar de `include/secrets.example.h`, no se sube al repo).
- Compilar: `pio run` · Subir: `pio run -t upload` · Monitor: `pio device monitor`.
